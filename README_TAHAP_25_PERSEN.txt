LUMIÈRE HOTEL — TAHAP 1 (TARGET 25%)

Isi tahap ini: 4 dari 15 halaman utama (sekitar 26,7% berdasarkan jumlah halaman):
1. index.html — Beranda
2. rooms.html — Daftar kamar
3. room-detail.html — Detail kamar
4. booking.html — Formulir pemesanan dan estimasi biaya

Aset bersama: assets/style.css dan assets/script.js.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html menggunakan browser.
3. Gunakan menu Kamar dan Pesan Kamar untuk mencoba alur tahap awal.

Fungsi pada tahap ini: desain responsif Bootstrap, navigasi dasar, pemilihan jenis kamar, validasi tanggal, perhitungan estimasi biaya, dan konfirmasi pemesanan demo di halaman. Pembayaran online/animasi pembayaran dan 11 halaman tambahan belum termasuk tahap ini; akan dikembangkan pada tahap berikutnya.

Catatan: ini adalah demo front-end. Tidak menyimpan data ke server dan tidak memproses transaksi uang sungguhan. Bootstrap, font, dan gambar memerlukan koneksi internet.
